# 🤖 Autonomous Research Agent

An AI-powered Multi-Agent Research Assistant that autonomously plans, researches, analyzes, critiques, and generates well-structured reports using LangGraph, RAG, and Mistral AI.

## 🌐 Live Demo

**Frontend:** https://autonomous-research-agent-lfjskrepm-code-with-lavanyas-projects.vercel.app/

**Backend API:** https://autonomous-research-agent-pgi3.onrender.com/

---

# ✨ Features

- Multi-Agent Architecture using LangGraph
- Intelligent Research Planning
- Real-time Web Search using Tavily
- RAG-based Document Question Answering
- PDF Upload & Retrieval
- Citation Generation
- AI Critic for Quality Review
- Markdown Report Export
- Modern Responsive UI
- Fully Deployed on Vercel & Render

---

# 🧠 Agent Workflow

User Question

# ⚙ Installation

```bash
git clone https://github.com/Code-With-Lavanya/Autonomous_Research_Agent
```

Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Frontend

```bash
cd frontend

npm install

npm run dev
```
